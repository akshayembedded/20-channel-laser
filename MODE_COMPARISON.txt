HTML MODE COMPARISON
====================
The full firmware sequence has 22 patterns. The first 18 match the HTML
presets in order, frame masks, and relative timing weights. Four additional
firmware chases follow. The live ADC controls step timing.

Columns enable high. Rows enable low. Row 2 uses PD7.
Strobing holds the rows enabled through both phases and switches columns.
